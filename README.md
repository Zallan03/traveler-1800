One sentence, at most 200 characters, explaining the modern internet to a
time traveler who has just stepped out of the year 1800 — using only things
a person from 1800 knows, and one true comparison they could hold in their
head.

> A printing press in every home, so a letter sent at breakfast is read in China before dinner, and the day's news with it.

`main.ts` writes the sentence to `/output/entry.txt`. Run it with Node 22+:

```sh
node main.ts
```
